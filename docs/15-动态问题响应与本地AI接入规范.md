# 动态问题响应与本地 AI 接入规范

## 1. 问题复盘

此前网页虽然有独立人物卡，但本地降级曾错误地使用固定主题分类。那只是早期实现缺陷，不是产品设计，更不是用户问题的分类体系。用户可以询问任何方向；系统必须直接理解本次问题本身，而不是先归类再选模板。

## 2. 当前修复

- 本地开发服务器新增 `/api/ai` 安全代理。
- 代理读取 CodexOne 已配置的 OneAPI 凭据和本地代理地址，浏览器端不接触或保存密钥。
- 默认模型为 `gpt-5.5`，可通过服务端 `ONEAPI_MODEL` 覆盖。
- `persona_main_comment`、`interaction_director`、`persona_interaction_reply`、`persona_user_reply` 均优先调用真实模型。
- `interaction_director` 全局最多挑一组关系；`persona_interaction_reply` 固定调用两次，分别生成挑战者第一句和原作者辩护第二句，随后结束。
- 网络、模型或解析失败时，才降级到本地人物专属回复。

## 3. 动态响应硬规则

1. 用户问题是开放域输入，可以涉及任何领域、知识、事件、判断、情绪、关系或想象，不设主题白名单。
2. 不得先把问题划入职业、感情、价值、通用或任何其他预设类型；不存在“类型 → 回答模板”的映射表。
3. 每条主评论必须直接回应本次朋友圈正文中的实际内容、具体对象、限制、冲突、事实或数字。
4. 评论至少自然提到用户原文中的一个具体关键词，或投票选项中的具体表述。
5. 不得复制完整问题，不以“你问……”复述开场；必要关键词控制在 1-2 个，主要篇幅用于人物自己的判断与论证。
6. 同一人物面对任意两个不同问题时，都应根据各自事实形成不同的核心论证和用词。
7. 人设卡只约束人物的价值观、思考方式和表达风格，不能替代对问题本身的理解。
8. 回答前先在内部概括核心追问，并判断问句是在求解释、因果、评价、事实澄清、思想讨论还是明确选择；这不是主题分类，而是防止答非所问。
9. 长问题必须完整传入并通读，优先理解末尾问句和全文对照概念；不得按前 N 个字截断后作答或显示破碎引用。
10. 观察性、解释性和因果性问题不得被人物口头倾向改写成去留、承担后果或立即行动。王阳明的“知行合一”和嬴政的“决断”只在语义适用时使用。
11. 主评论默认直接作答，不引用用户原句开头。禁止引号包裹问题、截断后加省略号，也禁止同批人物共享“先看/在回答/给/别让/写下 + 问题”的起手结构。
12. 用户短追问仍要继承原朋友圈问题，避免把“为什么”当成孤立新问题。
13. 点击发表后必须先立即创建并显示用户动态，人物生成在后台继续；不得让用户为了等待 6-8 次模型调用而停留在发布页。
14. 生成完成后内容进入待刷新池，仍需用户主动点击刷新才展示，保持朋友圈产品规则。
15. 刷新不得用旧页面状态覆盖正在后台生成的结果；如果用户已经点过刷新，而模型随后完成，本次生成结果应直接显现，不要求用户猜测何时再点一次。
16. 页面关闭或本地服务中断时，状态为 `generating` 且尚无待展示评论的历史动态，重新打开页面后必须按原参与者自动续跑。
17. 状态为 `failed` 的历史动态在用户点击“刷新朋友圈”时自动重试，不要求删除原动态或重复发布问题。

## 4. 本地安全代理

- 地址：`POST /api/ai`
- 只允许四种已登记任务。
- 请求体上限约 70KB，历史仅保留最近 6 条。
- 密钥只由 Node/Vite 服务端读取：优先 `ONEAPI_API_KEY`、`OPENAI_API_KEY`，否则读取 `~/.codex-one/auth.json`。
- 前端源码、localStorage 和浏览器网络请求中均不写入密钥。
- 返回必须是 JSON；服务端可从 Markdown 代码块或少量外围文本中提取 JSON。

## 5. 离线降级

离线 mock 不含主题分类器。它直接读取用户原问题和投票选项，再用各人物不同的思考方式回应具体内容。它仍不等同于真实模型，但必须满足：

- 两个不同问题的同一人物回复不相同。
- 回复中可看到原问题或选项的具体关键词。
- 14 人保持不同论证结构。
- 页面不出现“占位评论”或统一助手建议。

## 6. 官方平台迁移

官方平台若有模型调用能力，应把 `/api/ai` 替换为其安全服务端函数或平台内置模型动作，同时保留 `callAI` 函数签名、四种任务、独立人物卡和输出校验。不得把 API 密钥直接放入 HTML 或前端 JavaScript。

## 7. 开放域验收问题

测试题只是覆盖面样本，不是类别定义。至少比较同一人物对差异很大的问题，例如：

- “工资翻倍但每天通勤四小时，要不要接受？”
- “升职要隐瞒同事犯错，我该不该答应？”
- “家人说我这个年纪就该结婚，我要听吗？”
- “火星上的一年为什么比地球长？”
- “如果记忆可以被复制，复制出来的还是我吗？”
- “这段新闻里的统计结论可靠吗？”

每题都必须围绕其实际事实作答，不得经由题型名称选择固定句式。新增任何测试题时，也不能因此新增一个对应的回答模板桶。

发布按钮验收：点击后立即返回信息流并看见动态；生成期间显示“人物正在阅读这条朋友圈…”，不表现为发布卡死。

恢复验收：生成途中点击刷新、关闭页面或本地服务中断，均不得永久丢失该动态的回复任务；恢复后仍沿用原问题、原投票和原参与人物。
