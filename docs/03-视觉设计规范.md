# 视觉设计规范

## 1. 视觉命题

看起来像一个熟悉、克制的微信朋友圈，但细节更干净，蓝灰姓名与粉红点赞共同制造“古人真的住进我的通讯录”的轻微错位感。

## 2. 适配策略

- 移动端基准宽度为 375-430px。
- 桌面端不把手机外壳画进产品；页面主体最大宽度 430px，居中呈现，外围使用低对比暖灰背景。
- 弹窗以整个电脑视口居中，而不是只相对手机画布居中。
- 最小点击区域 44px，正文最小字号 15px。

## 3. 色彩

- 页面白色：`#FFFFFF`
- 桌面外围暖灰：`#ECEAE6`
- 主要文字：`#191919`
- 次要文字：`#8B8B8B`
- 姓名蓝灰：`#576B95`
- 分割线：`#EDEDED`
- 评论浅灰底：`#F7F7F7`
- 主操作绿色：`#07C160`
- 点赞粉红：`#F05D7B`
- 菜单深灰：`#4C4C4C`
- 遮罩：`rgba(0, 0, 0, 0.36)`
- 占位头像浅蓝：`#CFE7F5`、`#BFDCEC`、`#D8ECF7`

## 4. 字体与层级

优先使用中文系统字体：`PingFang SC`、`Microsoft YaHei`、无衬线回退。产品本身是仿朋友圈工具，不额外引入具有强品牌感的网页字体。

- 顶栏标题：17px / 600
- 用户名、人物名：15-16px / 600，蓝灰色
- 动态正文：16px / 1.65
- 评论正文：15px / 1.55
- IP：12px，灰色，固定格式 `IP：洛阳`
- 按钮：15-16px / 500

## 5. 朋友圈主页

- 顶栏高约 52px，白底，可随页面保持在顶部。
- 封面比例约 430:260，背景图铺满裁切。
- 用户头像为 72px 方形圆角，不使用圆形；人物头像使用圆形。
- 用户名“我”以白字叠在封面右下区域，头像位于其右侧或下方。
- 动态左右留白 16px，作者头像 44px，正文与头像间距 12px。
- 评论区不做厚重卡片，仅用浅灰背景和轻分割线组织信息。

## 6. 加号菜单

- 加号是黑色圆形线框，保持清晰可点击。
- 菜单锚定加号下方右侧，宽约 180px，深灰背景、白字。
- 两个菜单项高度不小于 52px，中间一条半透明分割线。
- 展开使用 140ms 淡入和轻微上移，不使用弹跳动画。

## 7. 弹窗

- 桌面端宽度 420-520px，移动端宽度为视口减 24px。
- 白底，16-20px 圆角，轻阴影。
- 顶部标题居中，右上角关闭图标。
- 背景整体变灰，弹窗独立保持纯白。
- @好友弹窗内容可滚动；底部完成按钮固定在弹窗内。
- 投票输入框为细灰线或浅灰底，不使用高饱和边框。

## 8. 投票和评论动作

- 投票字母 A-D 使用 24px 圆形浅灰标签，选项文本保持单行优先、可换行。
- 人物投票后在对应选项下显示 20-24px 圆形头像组。
- 点赞和评论按钮使用极简线条，不使用 emoji。
- 点赞默认灰黑色，激活时描边和填充均转为粉红色。
- 评论按钮为中间含三个点的对话气泡。

## 9. 动效原则

- 页面切换：160-220ms 横向或透明度过渡。
- 弹窗：遮罩淡入，弹窗从下方 10px 上移并淡入。
- 刷新：刷新图标旋转一圈；内容整批淡入，不逐条播放。
- 支持 `prefers-reduced-motion`，用户关闭动效时仅保留状态变化。
