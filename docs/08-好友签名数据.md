# 好友签名数据

## 用途与优先级

本文档保留第一阶段的签名版本，便于追溯。第二阶段已由用户确认以最新完整人物卡为唯一权威；发生冲突时，以 `src/data/characters.json` 和 `docs/13-完整人物卡.md` 为准。

被第二阶段覆盖的三项为：武则天改为“无字碑上，任后人评说。”；李白改为“人生得意须尽欢。”；马克思改为“改变世界，而不只是解释它。”。人物 ID 也统一使用第二阶段短 ID。

人物运行数据的权威来源仍为 `src/data/characters.json`；本文件仅作第一阶段历史记录，不再直接上传官方平台。好友姓名统一使用规范写法“释迦牟尼”“嬴政”。
