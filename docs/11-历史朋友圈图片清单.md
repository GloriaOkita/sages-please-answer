# 历史朋友圈图片与来源清单

## 使用规则

1. 每条历史朋友圈使用一张从网络平台选择并下载到本地的历史照片、历史绘画、版画、手稿或同时代地点图。
2. 图片不要求是朋友圈文案所述事件的现场照片，但要与人物年代、地点或人生主题相符。
3. 每个人物第一条朋友圈的图片同时作为其好友朋友圈详情封面。
4. 页面不把时代氛围图描述成事件实拍；图片仅作视觉语境。
5. 优先选择 Wikimedia Commons、博物馆和公共档案馆等稳定页面；必须保存来源页 URL、作者/机构和许可或公版状态。
6. 本地目录固定为 `public/assets/moments/<人物ID>/`，文件名按 `01`、`02`、`03` 编号。

## 素材登记字段

```json
{
  "characterId": "zhangailing",
  "momentIndex": 1,
  "localPath": "/assets/moments/zhangailing/01.jpg",
  "sourcePage": "原始来源页面 URL",
  "sourcePlatform": "Wikimedia Commons",
  "title": "图片标题",
  "creator": "作者或机构",
  "license": "Public domain / CC BY / 其他",
  "usageNote": "民国旧上海时代氛围图，非事件现场"
}
```

## 当前执行标准

- 14 人各 3 张，共 42 张本地图片。
- 苏格拉底第三条为《克里同篇》拒绝越狱情节的史料改写。
- 网络不可用、来源页无法验证或许可不明时，不臆造来源；先使用明确标注为“待替换”的本地年代占位图，并在本清单记录未验证状态。
- 官方平台复刻时，图片文件与 `characters.json` 中 `moments[].image` 路径一并上传。
- 当前已完成 42 张图片下载与来源登记，详见 `docs/12-历史朋友圈图片来源登记.md` 和 `src/data/momentImageSources.json`。
